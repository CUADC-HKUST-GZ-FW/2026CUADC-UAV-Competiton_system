## 双机部署约束

同一 ONNX 可用于两台设备，但 TensorRT engine 必须分别在目标 Jetson 本机生成：

- NX163：`arrow_pose_3pt_airport1006_alpha05_fp16_opt3_nx163.engine`
- NX164：`arrow_pose_3pt_airport1006_alpha05_fp16_opt3_nx164.engine`

禁止在 NX163 与 NX164 之间复制 engine。部署时不得同时改动分类权重、置信度阈值、相机标定或任务参数；完成回放和全链路验收后再把状态更新为已部署。

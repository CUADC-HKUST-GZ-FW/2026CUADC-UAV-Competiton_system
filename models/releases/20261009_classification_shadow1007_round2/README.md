# 2026-10-09 阴影增强分类模型候选

本目录发布 10 月 7 日第二轮阴影增强训练中通过独立回归的两份分类模型。发布到 GitHub 仅用于留档、复现和后续设备部署；截至发布时尚未替换 NX163/NX164 上的活动权重。

## 模型

- 数字 101 类：`digit_cls_shadow1007_round2_candidate.pt/.onnx`
  - 类别 `00-99` 加 `empty`
  - 清晰回归：`808/808`
  - 独立深阴影回归：`788/808`
- 图案 13 类：`image_cls_shadow1007_round2_candidate.pt/.onnx`
  - 12 种图案加 `empty`
  - 清晰回归：`208/208`
  - 独立深阴影回归：`207/208`

数字模型选择训练 `best.pt`。图案模型选择清晰图全对且阴影结果最好的 `epoch0.pt`，并已去除优化器状态。两份最终打包权重均重新执行了逐样本回归。

## 导出验证

- ONNX：静态 `1x3x128x128`，opset 17。
- 数字输出：`1x101`；图案输出：`1x13`。
- 两份模型均通过 ONNX checker。
- 8 组随机输入的 PT/ONNX argmax 均为 `8/8` 一致。

图案检查点内嵌的第 12 类文字存在历史编码异常。运行时必须继续使用 `youth-vision-runtime/configs/youth_classes_image.txt`，其中索引 12 正确对应 `empty`。

## 版本与部署边界

- 旧模型发布目录完整保留，本发布不覆盖历史版本。
- 本目录只包含源权重和通用 ONNX，不包含任何 Jetson TensorRT engine。
- NX163 与 NX164 必须分别在本机从同一 ONNX 构建各自的 FP16 engine，禁止跨设备复制 engine。
- 正式替换前仍需停止飞行任务、备份设备当前权重，并完成无桨识别及全链路检查。

完整哈希、训练谱系和验收状态见 `manifest.json`。

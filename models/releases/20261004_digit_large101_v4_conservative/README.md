# 20261004 数字 101 类模型发布

本目录保存 1003 大规模增量训练中由用户在 2026-10-04 明确采用的保守模型，以及被替换版本的完整源模型备份。

## 当前模型

- PyTorch：`digit_cls_large101_1003_v4_conservative_best.pt`
- ONNX：`digit_cls_large101_1003_v4_conservative_best.onnx`
- 输入：`1x3x128x128`
- 输出：101 类，索引 `0-99` 对应 `00-99`，索引 `100` 对应 `empty`

新模型改善了近期实飞中的 `68 -> 88` 混淆。历史 0829 低照度留出集中仍有一张真 `85` 从正确退化为 `30`；用户检查该图后认为其清晰度与现役相机不匹配，并明确决定采用新模型。该已知回归仍保留在 `manifest.json`，没有从验收记录中删除。

## 旧版本备份

`previous/` 保存此前部署的 `digit_cls_balanced101_0903_night_v2_best.pt/.onnx`。部署脚本还会在每台 Jetson 上二次备份当前活动配置和设备专属 TensorRT engine。

## 双机部署规则

- NX163：用户 `nx163`，有线地址 `192.168.55.1`，生成 `..._nx163.engine`。
- NX164：用户 `nx164`，有线地址 `192.168.55.2`，生成 `..._nx164.engine`。
- 两台设备共享同一 ONNX，但 TensorRT engine 必须分别在本机生成，严禁互相复制。
- 使用仓库根目录的 `deploy/deploy_digit_model_20261004.sh`。先运行 `--check`，确认无人机任务进程已停止后再运行 `--apply`。
- 脚本不启动、停止或重启飞行任务；部署后仍需在无桨条件下做视觉和全链路检查。

完整哈希、训练谱系和离线验收结果见 `manifest.json`。

# 2026-10-06 坦克/卡车图案分类候选

这是针对自贡赛场低分辨率坦克被错分为卡车问题训练出的最新 13 类图案分类候选。权重已发布到 GitHub 供审计和新视频测试，但尚未批准部署。

## 文件

- `image_zigong_tanktruck_1006_candidate.pt`：PyTorch 候选权重。
- `image_zigong_tanktruck_1006_candidate.onnx`：静态 `1x3x128x128`、opset 17 ONNX。
- `manifest.json`：哈希、来源、PT/ONNX 一致性和回归结果。

## 关键结果

- 1005 网页截图中的真坦克：现役模型判卡车 `99.995%`，候选判坦克 `98.31%`。
- 0829 坦克/卡车留出：`16/16`。
- 历史图案回归：`266/276`，与现役模型一致。
- 真实 empty：`20/20`。
- 三组运输机回归：`46/47`、`47/47`、`16/16`，最长连续火箭兵误判为 `0`。
- PT/ONNX：随机输入 `8/8`、13 类真实样本 `13/13` argmax 一致。

## 使用边界

原始飞行录像已经丢失，唯一困难坦克证据来自网页截图且参与了训练，因此不能同时充当独立验证集。部署前必须补拍未参与训练的坦克和卡车视频，使用现役 Pose 裁剪进行双向混淆及 finalized 包 A/B 验证。未通过前，生产模型仍为 `20261004_image_zigong_airport_domain`。

NX163 与 NX164 必须各自在本机由 ONNX 构建 TensorRT engine，禁止跨设备复制 engine。

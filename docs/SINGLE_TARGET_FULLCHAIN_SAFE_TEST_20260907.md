# NX163 单标靶全链路安全复测

日期：2026-09-07

## 结论

单标靶链路的软件路径可以完成：

1. 识别清单与同时间戳 RTK、姿态数据进入地理解算；
2. 多帧结果达到门槛后生成 `confirmed` 坐标；
3. 单标靶桥接原值转发一次坐标；
4. 任务管理器通过安全门控后调用 `/fcu/goto_global`；
5. FCU 接口根据坐标和航向生成 A、B、R、C、D，并形成待插入航线。

本次只验证软件与 ROS 链路。测试在独立 `ROS_DOMAIN_ID=80` 中运行，FCU 接口强制为 `dry_run_goto=true`、`allow_mission_upload=false`，没有向真实飞控写任务。

## 模拟输入

- 飞机位置：`22.88190000, 113.48830000`
- MSL 高度：`35.0 m`
- 姿态：单位四元数
- RTK：固定解，水平精度 `0.1 m`
- 相机：当前 1440x1080 标定、向前偏 `20 deg`、偏移 `[0.418, 0.0, -0.09] m`
- 识别：连续注入 7 帧，类别 `85`，Pose `0.98`，分类 `0.99`
- 航线方向：`90 deg`

## 实测结果

- 地理解算在第 5 个观测达到确认门槛；
- 返回坐标：`22.88190000, 113.48842790`；
- R95：`0.3675 m`；
- 桥接发布次数：`1`，经纬度未发生改动；
- 任务管理器状态：`STANDBY -> EXECUTING`；
- 单次攻击锁存：已置位，后续同进程结果不会再次触发；
- FCU dry-run 收到的 C 点与识别返回坐标完全一致。
